# Бот студии «Ноготочки»

Telegram-бот бьюти-студии «Ноготочки»: консультация по услугам и ценам, ответы на частые вопросы и подсказки по записи. Стек — Python 3 и [aiogram](https://docs.aiogram.dev/) 3.

Бот **не принимает оплату** и **не подтверждает слот** — только направляет клиента по шагам записи.

## Возможности

- **Услуги и цены** — прайс и описание процедур
- **Частые вопросы** — FAQ из базы знаний
- **Запись** — шаги: услуга → предоплата → согласование времени с мастером
- **О студии** — кратко о мастере, режиме работы и условиях приёма

## Структура

```
bot.py                 # точка входа
config.py              # BOT_TOKEN из .env
app/
  handlers/user.py     # команды и меню
  keyboards/           # reply-клавиатуры
  data/knowledge.py    # услуги, FAQ, тексты
  utils/logging.py
claude.md              # паспорт бота
```

## Быстрый старт

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.

2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Настройте окружение:

```bash
copy .env.example .env
```

В `.env` укажите:

```
BOT_TOKEN=ваш_токен
```

4. Запустите бота:

```bash
python bot.py
```

В Telegram откройте бота и отправьте `/start`.
