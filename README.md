# Бот студии «Ноготочки»

Telegram-бот бьюти-студии «Ноготочки»: консультация по услугам и ценам, ответы на частые вопросы и подсказки по записи. Стек — Python 3, [aiogram](https://docs.aiogram.dev/) 3 и [DeepSeek](https://api-docs.deepseek.com/) API.

Бот **не принимает оплату** и **не подтверждает слот** — только направляет клиента по шагам записи.

## Возможности

- **Услуги и цены** — прайс и описание процедур (кнопки меню)
- **Частые вопросы** — FAQ из базы знаний
- **Запись** — шаги: услуга → предоплата → согласование времени с мастером
- **О студии** — кратко о мастере, режиме работы и условиях приёма
- **Свободные вопросы** — ответы через DeepSeek по файлу базы знаний в системном промпте
- **Связаться с человеком** — контакт администратора студии

## Структура

```
bot.py                 # точка входа
config.py              # BOT_TOKEN и DEEPSEEK_* из .env
app/
  handlers/user.py     # команды, меню и ИИ-fallback
  keyboards/           # reply-клавиатуры
  data/knowledge.py    # услуги, FAQ, тексты для кнопок
  services/            # DeepSeek, промпт, загрузка базы знаний
  utils/logging.py
claude.md              # паспорт бота
База знаний….md        # файл КБ для системного промпта
```

## Быстрый старт

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Получите API-ключ на [platform.deepseek.com](https://platform.deepseek.com/).

3. Установите зависимости:

```bash
pip install -r requirements.txt
```

4. Настройте окружение:

```bash
copy .env.example .env
```

В `.env` укажите:

```
BOT_TOKEN=ваш_токен
DEEPSEEK_API_KEY=ваш_ключ_deepseek
DEEPSEEK_MODEL=deepseek-chat
DEEPSEEK_BASE_URL=https://api.deepseek.com
ADMIN_NAME=Администратор студии
ADMIN_TELEGRAM=username_без_собачки
ADMIN_PHONE=+79991234567
```

Кнопка «Связаться с человеком» отправляет контакт администратора из `ADMIN_*`. Если указан телефон, бот также присылает карточку контакта Telegram.

5. Запустите бота:

```bash
python bot.py
```

В Telegram откройте бота и отправьте `/start`. Кнопки меню работают без ИИ; произвольный текст уходит в DeepSeek.

## Guardrails

Свободные ответы защищены ограничителями:
- жёсткие правила в системном промпте (роль нельзя сменить);
- детектор промпт-инъекций на входе;
- обёртка пользовательского текста как данных, не команд;
- фильтр утечек/срыва роли на выходе модели.

Проверка:

```bash
python -m unittest tests/test_guardrails.py
python scripts/check_prompt_injections.py
```
